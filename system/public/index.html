    Settings & troubleshooting

    Linux audio & desktop setup

    Maximum stream quality

    Automatic quality stays within your limits and changes resolution only after sustained pressure. Turn it off for fixed resolution. The source size and each guest’s maximum still apply; an insufficient connection can cause stutter or delay.

    Video codec & hardware tuning

    Checking hardware decoding…

    NVIDIA speed settings apply only when NVENC is used. H.265 stays on hardware; a guest that cannot use it receives H.264. For the lightest host load, use matching codec and quality settings on all screens.
